# BMW Global Sales Dashboard | Power BI

![BMW Global Sales Dashboard](./images/dashboard.jpg)

Overview
This project presents an interactive **Power BI dashboard** built from BMW’s global sales dataset (2010–2024).  
It transforms raw automotive sales records into a clear, visual story of performance, customer preferences, and regional trends.

Dashboard Highlights
- **5M** total cars sold  
- **$402.98B** total revenue  
- **11 BMW models** analyzed  
- **6 operating regions** covered  
- Sales performance trends from **2010–2024**  
- Regional sales distribution  
- Most preferred vehicle colors  
- Preferred fuel types  
- Average engine size & mileage by fuel type  
- Interactive filtering by BMW model and transmission type  

Tools & Techniques
- **Power BI** for visualization  
- **Power Query** for data preparation and transformation  
- Data filtering, sorting, and type management  
- Custom column creation  
- Interactive dashboard design  
- Business storytelling through visuals  

Objective
The main goal of this project is to convert raw BMW sales data into an **interactive business dashboard** that highlights key sales trends and customer preferences, making insights easy to understand and actionable.
